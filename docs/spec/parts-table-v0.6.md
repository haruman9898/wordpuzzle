# アルファベット分解パズル — パーツ分解表 v0.6

作成: 2026-11-26（v0.5 を差し替え）
変更理由:
- （ユーザー提示）N = V + I、Z = V + I、E = F + I
- （ユーザー指摘）U = I + C + I は発想が難しい → Muse提案の **U = J + J**（Jと反転したJで底で合わせる。B = D + D と同じ「同じパーツ2個」型）を、ユーザーが 2026-11-26 に採用
- （v0.5から継続）角パーツは V 1種に統一
- （v0.4から継続）F = L + I、J = J
- （v0.3から継続）B = D + D、D = I + C、Y = V + I、G = C + L のように、**別の文字として成立する形をパーツにする**／S字パーツは採用しない

## 大原則（v0.6）

1. **パーツ名 = 形の名前**。大きさの違いは名前で区別しない。I は直線、C はカーブ、V は角（アングル）、という「形」を指し、大きさははめる枠に合わせて変わる。大小ペアのパーツは存在しない。
   - 例: P の C は小さく、D の C は大きい。どちらも C パーツ。
   - 例: A の横棒も、Y の下の縦棒も、どちらも I パーツ（回転・長さ違い）。
   - 例: A の V は大きく、W の V は小さい。どちらも V パーツ（W は V を2個使う）。
2. **複合パーツを認める**。D・L・O・P・F のように「I + C」などでできた形も、それ自体を1パーツとしてプールに入れる。だから B = D + D、R = P + I、Q = O + I、E = F + I が成立する。
3. **S字パーツは存在しない**。文字 S 自体は C + C（反転）で作る。v0.2 で短い棒の略号に「S」を使ったのは紛らわしい表記だったので廃止した（短い棒という独立パーツも廃止し、直線はすべて I に統一）。

## 残っている論点

1. D と P はどちらも素材では I + C。パーツとして別々に存在するのは「大きさと閉じ方」が違うため。絵で並べて区別できるか確認が必要（見本ページで確認中）。
2. 複合パーツ（D, L, O, P, F）がプールにあると、同じ文字に別解が出うる（例: B は D+D でも、素材で I+C+C でも作れる）。ステージごとに「使えるパーツをプール側で決める」設計なら問題にならない想定。
3. 3個必要な文字は H（I×3）と M（I+V+I）だけになった。この2文字に複合パーツでの短縮があるかは未検討。
