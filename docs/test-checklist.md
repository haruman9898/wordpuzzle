# 試遊チェックリスト（proto3）

**開発用の表示（診断表示・⚙）は、URL の末尾に `?dev=1` を付けて開いた時だけ出ます**（例: `https://haruman9898.github.io/wordpuzzle/?dev=1`）。一度付けると保存され、`?dev=0` で消えます。普通に遊ぶだけなら、付けなくて構いません。

対象: iPhone（iOS 17.4 以降）の Safari。公開 URL を開く。画面上部の診断表示に BUILD `proto2-a` と出ているか確認する（古い版が出ていたら、再読み込み）。

## 最初に（振動・音）
1. 設定 → サウンドと触覚 →「システムの触覚」がオンか確認する。
2. 診断表示の `振動` を読む。⚙ → 「本物のスイッチ」を指で直接タップして、触覚があるか確認する。
3. ⚙ の「iPhone の振動方式」を順に変えて、そのつど「弱・中・強」を押す。どの方式で振動があったか教えてください。
4. 「音テスト」を押す。サイレントスイッチのオンとオフで、音が鳴るか確認する。
5. ゲームを開いた時、他のアプリの音楽が止まるか。「再生中」の表示が出るか。（出るなら ⚙ の「無音ループ」をオフにして再読み込み。）

## 遊んで確かめること
- **ステージの流れ**: タイトル → ステージ選択 → プレイ → 結果。ステージ1〜3 を順に遊ぶ。
- **制限時間は妥当か**: ステージ1（20秒）、2（30秒）、3（35秒）が、緩い・適正・厳しいのどれか。単語完成の +2秒ボーナスは、効いている実感があるか。
- **星**: ⭐3 が取れそうか。取りにくすぎ・簡単すぎないか。
- **手触り**: 掴みやすさ、指の上に浮かぶ位置、吸着（磁石のように引き寄せられる感じ）、傾き。
- **演出**: はめた時の光の輪と火花、単語完成の画面の揺れ、コイン、単語が切り替わる時のスライドとパーツの飛び込み。
- **音**: 効果音の気持ちよさ、BGM（邪魔でないか。⚙ でオフにできる）。
- **ヒント**: 5秒止まった時の震えと、枠の脈打ち。
- **一時停止**: ⏸ ボタン、ホームに戻って戻ってきた時に時間が止まっているか。
- **残り10秒以下**: 赤い点滅と警告音。

## 比べてほしいこと
- ⚙ → パーツの見せ方: `matched`（枠と同じ形）と `canonical`（型ごとの標準形）で、どちらが良いか。

## 報告
- 何ステージか遊んだあと、⚙ →「ログをコピー」で出るテキストを貼ってください。診断表示（FPS・振動の方式）も含まれます。
- 一番気になった点を、遠慮なく教えてください。

## 振動の実験（proto2-c）
iPhone で「本物のスイッチ」は振動するのに、コードからは出ない状況の原因を絞るための実験です。
1. ⚙ を開き、「振動の実験（iPhone）」まで下にスクロールする。
2. 「iPhone の振動方式」を **ondemand** にして、A〜H の四角を1つずつタップ（H はドラッグして離す）。**振動したものの記号**を控える。
3. 方式を **label-onscreen** に変えて、もう一度 A〜H を試す。
4. 結果を、方式ごとに教えてください（例: 「ondemand は G だけ、label-onscreen は G だけ」）。
5. 「はめた時の振動の場面」を `touchend` に変えて、実際のゲームで振動するかも試す。

読み方: G（透明な label を直接タップ）だけが振動する場合、iPhone はコードからの振動を塞いでいます。その場合は、アプリ化の時に本物の触覚を使います。

## きせかえ（proto3）
- タイトルまたはステージ選択の「🎨 きせかえ」から入る。背景（5種）と、文字の色（5種）を、コインで買って選べる。
- 確かめること: 買う・つかうの流れが分かりやすいか。買った後に、遊ぶ画面（文字の色・背景）がすぐ変わるか。「よぞら」「ネオン」で、文字や枠が読みやすいか。価格（30/50/80/120）が、遊んで貯める感覚に合っているか。
- 開発メニュー（`?dev=1`）に、「コイン +100」と「着せ替えを初期化」がある。

## ステージ4〜6（proto3-b）
- ステージ3をクリアすると、ステージ4が開く。ステージ4〜6 は、**お邪魔パーツ**（そのワードに使わない、どの枠にもはまらないパーツ）が混ざる。
- 確かめること: お邪魔パーツが、**邪魔として面白い**か（見分けるのが楽しい／面倒なだけ、のどちらか）。制限時間（45/50/60秒）の、緩い・適正・厳しい。5文字の単語で、パーツが小さすぎて掴みにくくないか。
- 難易度カーブ: ステージ1→6 で、「次々クリアできる爽快感」と「だんだん難しくなる感じ」のバランスはどうか。

## 単語のイラストと、ことばずかん（proto4）
- ステージ2以降で、単語を完成させると、絵がポンと弾けて出る。初めての単語には「NEW!」とコインのボーナス（+5）。
- 確かめること: 絵の大きさ・出るタイミング・弾け方（気持ち良いか／やりすぎか）。「PERFECT!」・コイン・火花と一緒に、にぎやかすぎないか。次の単語に移る時の絵の消え方。ステージ1（絵なし）の寂しさ。
- 「📖 ずかん」（タイトル／ステージ選択）: 完成した単語が、色付きの絵で並ぶか。タップで大きく見えるか。シルエットの「？？？」が、集めたくなるか。
- 絵を見せる位置（完成時のパーツ置き場）以外の案があれば教えてください。

## カクつきの原因の切り分け（proto4-c）
**注意:** `?dev=1` は保存されるので、一度開くと、普通の URL でも開発モード（診断表示つき）になります。普通のモードに戻すには、`?dev=0` を付けて開いてください。
「`?dev=1` の時だけ重いのか」「遊びすぎて端末が熱くなったのか」を分けるため、次の順で遊んでください。
1. `https://haruman9898.github.io/wordpuzzle/?dev=0` を開く（診断表示が消えているか確認）。ステージ4〜6で、10語ほど遊ぶ。
2. `https://haruman9898.github.io/wordpuzzle/?dev=1` を開く。そのまま10語ほど遊ぶ。
3. もう一度 `?dev=0` を開いて、10語ほど遊ぶ。
4. `?dev=1` を開いて、遊ばずに、⚙ →「ログをコピー」で出る文章を貼る。（「計測の記録」に、1語ごとの時刻・モード・フレーム時間が出ます。）
5. 分かる範囲で教えてください: 低電力モードはオンでしたか。遊んでいる間、本体は温かくなりましたか。カクつきは、遊び始めてすぐか、しばらくしてからか。演出の時か、パーツを動かす時か。
