# 手触り確認版（proto1）の試遊チェックリスト

対象: iPhone（iOS 17.4 以降）の Safari。公開 URL を開く。

## 最初に
1. 画面上部の診断表示を読む。`proto1-a`（BUILD）、`振動` が `ios-switch` か `none` か、`FPS`、`音` が `running` か。
2. ⚙ を開き、「振動テスト」の弱・中・強を押す。**振動を感じるか**を確認する。
3. 「音テスト」を押す。**サイレントスイッチがオンの時とオフの時**で、音が鳴るか確認する。

4. **ゲームを開いた時、他のアプリの音楽やポッドキャストが止まるか。** コントロールセンターに「再生中」の表示が出るか。（出る場合は、⚙ の「無音ループ」をオフにして再読み込みし、サイレントスイッチ下の音がどうなるか確認する。）

## 遊んで確かめること
- パーツを掴みやすいか（細い線のパーツが特に）。掴んだ時、指の上に浮かぶ位置は良いか。
- 吸着の強さは良いか（強すぎる／弱すぎる）。
- はめた時の音・振動の気持ちよさ。連続ではめた時の音程の上がり方。
- 単語完成の演出（文字が跳ねる、PERFECT!、コイン）。
- ヒントの震えが始まるタイミング（5秒）。
- ドラッグの追従に、遅れや引っかかりがないか。

## 比べてほしいこと
- ⚙ → パーツの見せ方: `matched`（枠と同じ形）と `canonical`（型ごとの標準形）で、どちらが良いか。

## 報告
- 何単語か遊んだあと、⚙ → 「ログをコピー」で出るテキストを貼ってください。診断表示（FPS・振動の方式）も含まれます。
